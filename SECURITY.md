# Security Policy

## Supported Versions

CodeArmory is currently in alpha. Security fixes are applied to the latest release only.

| Version | Supported |
|---------|-----------|
| alpha-latest | Yes |
| older | No |

## Reporting a Vulnerability

**Please do not report security vulnerabilities through public GitHub issues.**

To report a vulnerability, use [GitHub's private vulnerability reporting](https://github.com/code-armory-app/codearmory/security/advisories/new).

Include as much of the following as possible:

- Type of issue (e.g. authentication bypass, privilege escalation, injection)
- Affected component (Gatekeeper, Blueprints, Conductor, CLI)
- Steps to reproduce
- Potential impact

We will acknowledge your report within 48 hours and aim to publish a fix within 14 days for critical issues.
