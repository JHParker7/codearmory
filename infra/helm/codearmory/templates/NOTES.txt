  Service type is LoadBalancer — run the following to get the external IP:

  Access conductor from within the cluster at:
    http://{{ include "codearmory.fullname" . }}-conductor:{{ .Values.conductor.port }}

  Port-forward for local access:
    kubectl port-forward svc/{{ include "codearmory.fullname" . }}-conductor {{ .Values.conductor.port }}:{{ .Values.conductor.port }} -n {{ .Release.Namespace }}
{{- end }}

Before production use, make sure you have set:
  - gatekeeper.secret.gatekeeperServices        (service auth keys for all services)
  - registry.secret.gatekeeperServiceKey
  - registry.secret.serviceAccounts            (e.g. "conductor=<key>")
  - registry.secret.adminAccounts              (e.g. "admin=<key>")
  - conductor.secret.registryServiceKey        (must match registry.secret.serviceAccounts entry)
  - blueprints.secret.encryptionKey             (openssl rand -hex 32)
  - blueprints.secret.gatekeeperServiceKey
  - conductor.secret.conductorForwardKey
  - forge.secret.conductorForwardKey
  - forge.secret.gatekeeperServiceKey
  - workflows.secret.gatekeeperServiceKey
  - workflows.secret.hooksTriggerKey            (openssl rand -hex 32, must match hooks)
  - tickets.secret.gatekeeperServiceKey
  - hooks.secret.gatekeeperServiceKey
  - hooks.secret.hooksTriggerKey                (must match workflows.secret.hooksTriggerKey)
  - postgresql.auth.postgresPassword            (change from default)
